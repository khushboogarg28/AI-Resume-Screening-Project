# AI Resume Screening & Interview Recommendation Platform

An AI-powered web platform designed to analyze resumes, match candidates with suitable job roles, and provide interview recommendations.

## 🚀 Project Overview

The platform helps simplify the initial recruitment process by analyzing candidate resumes and presenting useful insights for recruiters and candidates.

The frontend provides an interactive and user-friendly interface for resume screening, candidate analysis, and interview recommendations.

## ✨ Features

- 📄 Resume Upload & Screening
- 🤖 AI-Based Resume Analysis
- 🎯 Job Role Matching
- 📊 Candidate Analysis Dashboard
- 💼 Interview Recommendation
- 🔍 Skill & Qualification Analysis
- 📱 Responsive User Interface
